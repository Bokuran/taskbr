      # TBH: Task Bar Hero — Idle RPG

      Полностью автономная idle-RPG на чистом JavaScript. Откройте `index.html` в браузере (или через Live Server).

      ## Что уже включено
      - Автобой без кликов и активных навыков.
      - У героев есть HP над головой; монстры атакуют переднего живого героя.
      - Целительница лечит самого раненого союзника.
      - Экипировка падает с монстров и боссов, есть автоэкипировка (кнопка или `E`).
      - Броня даёт HP, защиту и реген конкретному герою.
      - Лазарет повышает HP всего отряда, золотая жила увеличивает золото.
      - Волны, боссы каждые 5 волн, отступление при поражении, перерождение, офлайн-доход.
      - Спрайты героев могут быть картинкой (`assets/heroes.png`) или пиксельным кодом.

      ## Структура
      - `index.html` — разметка.
      - `css/style.css` — оформление.
      - `config/` — герои, монстры, зоны, предметы, баланс.
      - `js/` — движок: состояние, бой, интерфейс, звук, автоэкипировка.
      - `assets/` — необязательный лист героев `heroes.png`.

      ## Управление
      - `P` — пауза.
      - `M` — звук.
      - `H` — справка.
      - `E` — автоэкипировка.
      - Кнопки в шапке: пауза, скорость ×1–×3, звук, справка, сброс.

      ## Спрайты-картинки
      Положите лист в `assets/heroes.png`. Порядок персонажей: рыцарь, лучница, маг, целительница. Фон лучше делать однотонным (например, розовым) — движок сам вырезает фон и режет лист на 4 частей. Если файла нет, используются запасные пиксельные спрайты.

      Настройки в `config/heroes.js`:
      - `src` — путь к картинке.
      - `index` — номер персонажа на листе (0..3).
      - `count` — сколько персонажей на листе.
      - `pixelHeight` — внутреннее разрешение (48 оптимально).

      ## Добавление контента
      Скопируйте любой блок в нужном файле `config/*.js`, задайте уникальный `id` и обновите страницу. Для новой зоны добавьте её в `config/levels.js`; для нового монстра — в `config/monsters.js` и пропишите его id в зоне.
